# network: computers talking

| File | What it shows | Run it |
|---|---|---|
| `pong.py` | A computer that answers every message it gets | On one computer, first |
| `ping.py` | Sending messages and waiting for answers | On another computer on the same cables |

Both computers need these files: `git clone helpme` on each. Behind antennas, computers on
different networks reach each other the same way, by `"external IP:port"`.
