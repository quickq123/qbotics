# internet: the real one

An **Uplink** on a computer's cable network lets its programs make HTTPS requests (a laptop and a
Server have one built in).

| File | What it shows |
|---|---|
| `zen.py` | Asking a website for data with `requests`, and reading it as text or JSON |

**git** works through the Uplink too: `git clone https://github.com/<someone>/<repo>` copies a
GitHub repository here, the way `helpme` came. `git status`, `git pull` and `git push` work in it.
