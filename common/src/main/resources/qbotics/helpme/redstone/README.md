# redstone: Logic Pins and events

A **Logic Pin** is a plate on a cable that reads or drives redstone on the block it points at.

| File | What it shows | You need |
|---|---|---|
| `door.py` | A lever opens a door (or lights a lamp) for three seconds; the program sleeps until the lever moves | Two Logic Pins: `button` pointing at a lever, `door` pointing at a door or lamp |
