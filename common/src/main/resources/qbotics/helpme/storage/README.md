# storage: items, chests and Serial Buses

An **Item Serial Bus** is a plate on a cable that works the container it points at. Put a chest
down, a cable beside it, and right-click the chest holding the bus.

| File | What it shows | You need |
|---|---|---|
| `count.py` | What a chest holds, totals, and counting by name, tag or pattern | A bus on a chest |
| `sort.py` | Moving everything from an inbox chest to a store, except what you keep out, whenever something arrives | Two buses, named `inbox` and `store` |

For a storage screen with item pictures and a search box, see `/helpme/displays/web_storage`.
