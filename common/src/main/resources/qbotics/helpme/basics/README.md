# basics: start here

Nothing but a computer is needed for the first two.

| File | What it shows | Run it |
|---|---|---|
| `hello.py` | `print`, `input`, loops and functions | `run hello.py` |
| `notes.py` | Saving and reading a file on the computer's drive | `run notes.py`, twice |
| `devices.py` | What is on this computer's network, and naming the computer | `run devices.py` (add some cables and devices first) |

Next: `/helpme/storage` to move items, or `/helpme/displays` for screens.
